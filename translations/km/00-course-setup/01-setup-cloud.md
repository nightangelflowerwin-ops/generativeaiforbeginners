# ការតំឡើងពពក ☁️ – GitHub Codespaces

**ប្រើណែនាំនេះ ប្រសិនបើអ្នកមិនចង់ដំឡើងអ្វីទាក់ទងជាលokal។**  
Codespaces ផ្តល់ជូនអ្នកនូវVS Code នៅលើកម្មវិធីរំញ័រដោយឥតគិតថ្លៃជាមួយអ្វីដែលត្រូវការបានដំឡើងរួចហើយ។

---

## 1.  ហេតុអ្វីបានជា Codespaces?

| អត្ថប្រយោជន៍ | មានន័យដល់អ្នកយ៉ាងដូចម្តេច |
|---------|----------------------|
| ✅ មិនចាំបាច់ដំឡើង | ដំណើរការលើ Chromebook, iPad, កុំព្យូទ័រពិសាលីសាលា… |
| ✅ កុងតឺន័រអភិវឌ្ឍបានស្រាប់ | Python 3, Node.js, .NET, Java មានក្នុងនេះរួចហើយ |
| ✅ ផ្តល់អត្រាឥតគិតថ្លៃ | គណនីផ្ទាល់ខ្លួនទទួលបាន **120 ម៉ោងកូរ/ 60 GB-ម៉ោងក្នុងមួយខែ** |

> 💡 **យុទ្ធសាស្ត្រ**  
> រារាំងអត្រារបស់អ្នកឱ្យមានសុខភាពល្អដោយ **បញ្ឈប់** ឬ **លុប** codespaces ដែលគ្មានការប្រើប្រាស់  
> (មើល ▸ បញ្ជីពាក្យបញ្ជា ▸ *Codespaces: Stop Codespace*).

## 2. បង្កើត Codespace (បាល់គ្រប់)

1. **ចម្លង** រុករកនេះ (ប៊ូតុង **Fork** នៅលើស្តាំខាងលើ).  
2. នៅក្នុងចម្លងរបស់អ្នក ចុច **Code ▸ Codespaces ▸ Create codespace on main**.  
   ![Dialog showing buttons to create a codespace](../../../translated_images/km/who-will-pay.4c0609b1c7780f44.webp)

✅ បង្ហាញផ្ទាំង VS Code លើកម្មវិធីរំញ័រ និងកុងតឺន័រអភិវឌ្ឍកំពុងចាប់ផ្តើមសាងសង់។
នេះអាចចំណាយពេល **~2 នាទី** លើដងដំបូង។

## 3. បន្ថែមកូនសោ API របស់អ្នក (វិធីសុវត្ថិភាព)

### ជម្រើស A Codespaces Secrets - ផ្ដល់អនុសាសន៍

1. ⚙️ រូបតំណាងកង់ -> បញ្ជីពាក្យបញ្ជា-> Codespaces : គ្រប់គ្រង user secret -> បន្ថែម secret ថ្មី។
2. ឈ្មោះ: OPENAI_API_KEY
3. តម្លៃ: បិទបញ្ចូលកូនសោរបស់អ្នក → បន្ថែម secret

ទាំងនេះប៉ុន្តែ-code របស់យើងនឹងយកវាមកដោយស្វ័យប្រវត្តិ។

### ជម្រើស B ការ .env file (ប្រសិនបើអ្នកមានត្រូវការពិត)

```bash
cp .env.copy .env
code .env         # បញ្ចូល OPENAI_API_KEY=កូនសោរបស់អ្នកនៅទីនេះ
```
